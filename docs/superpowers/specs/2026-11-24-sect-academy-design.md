# Sect Academy — design

Date: 2026-11-24. Status: built (first usable version). Evidence for the choices
below is in `docs/research/sect-academy-design-inputs.md`.

## Intent

Turn the project into a learning app you open every day: French, Spanish and
entry cyber-security certifications, wrapped in the cultivation theme as a real
game where studying is how you raise a sect.

"Usable day to day" was taken to mean:

- it works on a bare install — no LLM key, no network, no database;
- one obvious action when you open it ("Begin cultivation"), 10–20 minutes long;
- progress survives restarts, and a missed day never destroys anything;
- it is comfortable on a phone (installable PWA) as well as a desktop.

## Goals, non-goals, anti-goals

**Goals**

- Curated, original, offline courses: French A1, Spanish A1, Security+ (SY0-801),
  Network+ (N10-009), ISC2 CC (Sept 2026 outline) — "the basics", ~1,200 items.
- A scheduler that decides what to study each day (FSRS-6, default weights, 90%
  target recall) so the learner never has to.
- Exercises that harden as memory matures: recognise → recall → type → dictation.
- Timed mock exams ("trials") sampled by the official domain weights.
- A sect-raising game whose best strategy is the best study strategy.

**Non-goals (this version)**

- LLM-generated content. The existing AI Learning Center stays at `/learn` as an
  optional tutor; nothing here depends on it.
- Multiple learners, leaderboards, social features.
- A2+ language content, performance-based exam questions, speech recognition.
- Removing the fleet dashboard. It moved from `/` to `/command` and is untouched.

**Anti-goals** (would make it a failure even if it "works")

- Rewarding volume over memory: XP farming, paying for self-graded "I knew it".
- Punishing absence: lost buildings, guilt mechanics, streak anxiety.
- Wrong content. A learning app that teaches errors is worse than none.

## Approaches considered

1. **Extend the existing LLM Learning Center** (`learning.py`). Rejected as the
   core: every lesson, quiz and drill is generated by a model, so with no backend
   configured nothing works, and generated content cannot be proofread ahead of
   time. Kept as the optional tutor.
2. **Offline-first academy as a new package, the game on top (chosen).** Curated
   YAML packs + FSRS + server-side grading + a self-contained game module, served
   as a small vanilla-JS app shell at `/`. Fits the repo's conventions (no build
   step, FastAPI routers, default-off optional extras) and is fully testable.
3. **A separate standalone app/repo.** Rejected: the brief says *transition this
   project*, and the theme, art (`static/assets/sect`), auth and PWA plumbing
   already live here.

## Architecture

```
maybot_control_center/academy/
  packs.py     load + validate packs/*.yaml  (python -m …academy.packs)
  packs/       french_a1, spanish_a1, security_plus, network_plus, isc2_cc
  fsrs.py      FSRS-6 scheduler, pure Python
  engine.py    enrolment, sessions, grading, trials, stats
  game.py      the sect: qi, realms, rooms, disciples, missions, quests, streak
  state.py     one JSON file, always on (atomic write + daily .bak)
routers/academy.py    /api/academy/* and the pages /, /study, /library, /trials, /progress
static/academy/       index.html, academy.css, academy.js (one app shell)
```

### Study engine

- One content item = one FSRS card. New items are introduced in order, a unit at
  a time, rationed per course per day (default 8). Due reviews always come first;
  when the backlog exceeds two sessions' worth, new items are held back.
- Format by maturity: vocab is met (intro card), recognised (choose the meaning),
  recalled (choose the word), then typed from memory, with dictation every third
  review when the device has a voice for the language. Cloze: choose, then type.
  Concepts alternate definition→term and term→definition. MCQs are always tests.
- Grading is server-side. Wrong = Again; right with a missing accent or a
  one-letter slip = Hard; right = Good. A wrong article is never forgiven, and
  on words under four letters the accent *is* the word (où/ou, tú/tu).
- Only the first answer to an item in a session is scheduled. A missed item comes
  back in the same session until it is answered correctly once.
- "I know this already" on an intro card converts the check into a typed answer;
  only a correct typed answer earns the Easy grade (an 8-day first interval).
- Trials: certs draw `exam.questions` MCQs by largest-remainder apportionment of
  the official domain weights; languages draw 20 typed items from everything
  introduced. Timed; overtime fails. Every miss becomes a card due tomorrow.
- The learner's day is their local day (the UI reports its UTC offset).

### The game

- **Qi** (your cultivation) comes only from graded answers: due review 10, new
  item 6, wrong 3/2, +2 for typed recall, practice 1 (capped at 30/day). Since
  the schedule bounds how many graded answers exist, qi cannot be farmed.
- **Realms**: 8 realms × 4 stages; stage cost `120 + 320·step` qi (about a year of daily study for the whole ladder). A stage at
  Peak waits for a **tribulation** — passing any trial — before the next realm.
- **Spirit stones**: session reward with daily diminishing returns (100/50/10%),
  three daily quests, a 5-of-7 weekly goal, trials, missions, and capped passive
  income. A 60-day simulated learner was used to tune this so idle income stays
  a minority share of what a day's study earns.
- **Rooms** (the cut-away HQ artwork is the map): three course halls that grow
  only by completing units, plus Spirit Vein, Meditation Chamber, Disciple
  Quarters, Trial Grounds, Mission Hall, Alchemy Hall, Treasure Vault and the
  Hall of the Sect Master (sect rank, gated on items learned).
- **Disciples** are recruited with tokens earned by learning (every 30 items,
  first trial pass per course) — pick one of three candidates. Posted to a course
  hall they earn in proportion to how well you currently *remember* that course,
  so neglecting reviews makes a hall go quiet.
- **Forgiveness**: grace pills cover missed days automatically, seclusion is a
  holiday mode, and the qi-flow multiplier only eases 10% per missed day
  (0.5–2.0). Nothing built is ever lost.

## Decisions made on the builder's call (not the owner's)

- Security+ targets **SY0-801** (launched 17 Nov 2026), not the retiring SY0-701.
- The fleet Command Hall moved to `/command`; `/` is now the academy.
- Academy state is a JSON file, not the optional SQLite store, so it persists by
  default (`MAYBOT_ACADEMY_FILE`; sits next to `MAYBOT_DB` when that is set).
- Reads need any role; anything that changes progress needs the operator role.
- All economy numbers are starting values to playtest, not researched constants.
- Spain Spanish is the default form; Latin American variants are accepted.

## Left for later

- A2 packs; months, larger numbers and pronominal verbs are thin in A1.
- Performance-based (PBQ-style) exam items; SY0-701 variant for early sitters.
- Per-user FSRS weight optimisation once enough review history exists.
- Reminders (the existing push/notify plumbing could send "reviews are due").
- A native-speaker pass on the language packs (they were written and
  independently proofread by models, not by a human teacher).
