# Realm Map sprite assets

The Realm Map renders buildings/props as isometric sprites. Each sprite has two
possible sources, resolved by `GET /api/sect/manifest`:

1. **Authored override** — `static/assets/sect/<name>.png` (this folder, top level).
   If present, it is used.
2. **Baked fallback** — `static/assets/sect/baked/<name>.png`, generated by
   `python tools/build_sect_sprites.py` (MagicaVoxel-style voxel renders).

So to replace a baked placeholder with real art, just drop a PNG named after the
sprite here. No code changes, no map rewrite.

## Sprite names

`grand_pagoda, pagoda, pavilion, lantern, tree, pine, cherry, crane, shrine,
stall, gate, crystal, fountain, observatory, forge, bell`

## Isometric spec (match these so art lines up)

- 2:1 isometric, **6 voxels per tile**, tile half-size `40 x 20` px (see
  `baked/manifest.json` → `tile`, `voxPerTile`).
- The sprite's **ground anchor** is where it meets the terrace (foot centre).
- Transparent background (PNG with alpha).

## Optional metadata — `static/assets/sect/manifest.json`

Authored PNGs can be any size; supply metadata so they place correctly:

```json
{
  "sprites": {
    "grand_pagoda": {
      "anchorX": 256, "anchorY": 470, "w": 512, "h": 540,
      "footTiles": 3.3,
      "scale": 1.0,
      "z": 0
    },
    "fountain": { "anchorFx": 0.5, "anchorFy": 0.78, "footTiles": 2.0 }
  }
}
```

- `anchorX/anchorY` + `w/h` → converted to fractional anchor; or give
  `anchorFx/anchorFy` (0..1) directly. Default `0.5, 0.9`.
- `footTiles` — how many tiles wide the sprite's footprint is (controls scale).
  Defaults to the baked value for that name.
- `scale` — extra size multiplier (default `1.0`).
- `z` — draw-order nudge within a location (higher = drawn later / more in front).

Anything omitted falls back to the baked sprite's metadata. The browser console
logs which sprites loaded as **external** vs **baked fallback** on each load.
